## How I approach building AI products

1. **Start with a user problem.** Define what the application should help someone accomplish.
2. **Integrate models responsibly.** Use existing model APIs where appropriate, validate inputs, and handle provider errors.
3. **Protect credentials.** Keep private API keys on the server and configure them through environment variables.
4. **Build for real users.** Make the interface responsive, handle loading and failure states, and document local setup.
5. **Test and improve.** Add automated checks where practical and identify limitations before scaling.
